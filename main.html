Raccourcis clavier et modes
Mode sélectionen mode sélection, le bouton suivant cycle les cibles sommet / segment / triangle
Backspacesupprimer le point sélectionné en mode vertex, les triangles dépendants du segment en mode segment, ou uniquement les triangles sélectionnés en mode triangle
⇧Backspacereinitialiser completement la scene (modale de confirmation)
CtrlZannuler
Ctrl⇧Zretablir
CtrlYretablir
CtrlSsauvegarder la scene en JSON
CtrlCcopier la sélection : points sélectionnés + triangles entièrement contenus (avec leur couleur)
CtrlXcouper la sélection (copie dans le presse-papiers puis suppression, annulable par Ctrl+Z)
CtrlVcoller dans le plan actif — chaque collage décale d'un demi-pas de grille pour se distinguer de la source ; le presse-papiers est interne à l'application (non partagé avec le système)
Alt←aligner X les points sélectionnés — tous prennent la coordonnée X du 1er point sélectionné (l'ancre, bouton Aligner X du panneau du bouton Aligner)
Alt→aligner Y les points sélectionnés — tous prennent la coordonnée Y du 1er point sélectionné (l'ancre, bouton Aligner Y)
Alt⇧←répartir X les points sélectionnés — espacement uniforme selon X entre les deux points extrêmes (qui restent en place, bouton Répartir X)
Alt⇧→répartir Y les points sélectionnés — espacement uniforme selon Y entre les deux points extrêmes (qui restent en place, bouton Répartir Y)
Gafficher / masquer la grille
Rréticule : off / simple / projection symétrique (cycle)
Pprévisualiser la scène (masque points de contrôle, axes, grille, HUD et boutons) ; un 2e clic (ou P) affiche tous les plans dans leur ordre ; Échap ou clic gauche pour quitter — molette = zoom, clic milieu = pan, aucune édition
Alt↑↓monter / descendre le plan actif d'un rang dans l'ordre des plans (dans la vue plans : monter le fait passer au-dessus, descendre en dessous) ; boutons de la barre d'outils (grisés aux bornes de l'ordre)
Kiosque (bouton)sélectionner le plan actif dans un kiosque 3D : chaque plan est affiché comme une carte inclinée autour d'un axe vertical virtuel — la position du pointeur fait varier l'inclinaison et met un plan en avant ; un clic le sélectionne comme plan actif et referme le kiosque, Échap annule
AltKouvrir / fermer le kiosque de sélection des plans
Cactiver / désactiver le mode cercle (cercle aussi dans le panneau Formes) : 2 clics sur le canvas (1er clic = centre, mouvement de la souris règle le rayon + l'angle de départ — le sommet 0 du polygone pointe vers la souris, 2e clic = valider) ; molette sur le canvas ou sur le bouton actif = nombre de côtés ; le mode se désactive après la création ; Échap = quitter le mode, clic droit = annuler le tracé
Formes (bouton)ouvre la liste des formes prédéfinies (cercle, rectangle, carré, triangle, pentagone, hexagone, étoile, anneau) : choisir une forme puis la tracer en 2 clics (1er clic = ancre, mouvement = taille et orientation pour les polygones, 2e clic = valider) ; l'étoile et l'anneau se tracent en 3 clics (1er = centre, mouvement = rayon + angle de départ, 2e = verrouille, mouvement = profondeur des branches / taille du trou, 3e = valider ; molette = côtés pour l'anneau) ; Échap = fermer le panneau ou annuler l'outil, clic droit = annuler le tracé
Clic milieu sur grillereinitialiser le pas
Molettezoomer (centre sur le curseur) ; pivoter si 2+ points sont selectionnes
Ctrl/CmdClic droit sur pointajouter le point à la sélection sans le déplacer. Maj+clic gauche = toggle. Clic gauche simple = remplace la sélection ; clic droit simple sélectionne et remplace la sélection.
Anneau orangeautour d'un sommet : plusieurs points sont superposés à cette position (doublons de scènes importées). Cliquer dessus (mode sommet) les sélectionne tous, puis le bouton Fusionner les regroupe en un seul.
Fusion par déplacement2e fonction du bouton Fusionner, utilisable si et seulement si un seul point est sélectionné : le clic arme le mode (bouton en vert, avec le rayon en px). Glisser le point sélectionné puis le relâcher près d'un autre point le fusionne avec lui ; la molette sur le bouton règle le rayon de fusion quand le mode est armé (20 px par défaut, 8 à 64 px, indépendant du zoom). Re-cliquer pour désarmer.
Palette de couleursle bouton Peinture ouvre la palette : clic sur un swatch = peindre ; le curseur Opacité règle l'opacité appliquée à chaque peinture (elle reste à votre dernière valeur, d'une session à l'autre) ; Ajouter enregistre la couleur du picker ; clic droit sur un swatch = le retirer ; double-clic = le modifier (Entrée valide, Échap annule) ; Défauts restaure les 8 couleurs d'origine. La palette est conservée d'une session à l'autre.
Clic milieu + dragdeplacer le viewCenter dans le sens du drag (pan)
AltGrClic-droit + dragdeplacer tous les plans ensemble (meme delta, quasi-mode). AltGr (Right Alt) declenche Ctrl+Alt sur la plupart des claviers.
Clic gauche + dragsélectionne uniquement par lasso ; il ne déplace jamais la géométrie
Clic droit simpleen mode édition, sélectionne uniquement l'entité la plus proche et désélectionne les autres ; dans le vide, efface la sélection
Clic droit + dragdéplace la sélection depuis n'importe quel point du canvas ; sans sélection, le mode triangle/segment peut sélectionner puis déplacer l'entité sous le pointeur
Ctrl/CmdClic droitajoute l'entité sous le pointeur à la sélection sans la déplacer
AltGrMoletterotation de chaque plan autour du curseur (5 deg/cran, cumulatif). Le pivot est la position de la souris dans la scene (= coords modele sous le curseur, suivi a chaque tick si elle bouge). Sans AltGr : molette pivote si 2+ points sont selectionnes, sinon zoom centre sur le curseur.
Ctrl0reinitialiser le zoom (100%, recentre sur l'origine)
