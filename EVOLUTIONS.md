# evolutions
## consignes
Le présent fichier liste les évolutions à réaliser et l'historique des évolutions réalisées ; les évolutions à réaliser sont à utiliser comme consignes pour effectuer des modifications de l'application MESHES DESIGNER ; tout process automatique qui viendrait à produire ces modifications déclenchera après accord de l'utilisateur les changements nécessaires à leur réalisation, produira et déclenchera les tests de contrôle, itérera sur les corrections en cas de dysfonctionnement, puis après confirmation par l'utilisateur que l'évolution est fonctionnelle, modifiera le présent fichier pour passer l'évolution du statut à réaliser au statut effectué. L'item à réaliser est supprimé et l'item effectué est ajouté avec mention de la date et du l'identifiant de commit ; le commentaire doit être précis, concis et orienté finalité sans informations techniques.
## évolutions à réaliser sur l'application
- mettre à disposition du concepteur une interface légère pour gérer les messages HUD ; 2 finalités : 1) internationalisation 2) associer un message à une action ; pour permettre cette association, il faut ajouter dans le code des identifiants à chaque action ; on définie une action comme un geste élémentaire effectuée sur un élément (bouton, sommet, segment, triangle) et faisant suite éventuellement à une action qui la précède directement
